NikoPet v0.1 (Forge 1.7.10)
PC (MCP 9.05): copy src/main/java/com into MCP src/minecraft/, copy src/main/resources/assets
 into the same source root, recompile, run.  Or: gradlew setupDecompWorkspace build (ForgeGradle 1.2, JDK 8).
Result jar -> mods/ folder (PC or Zalith's game folder; HBM + NikoPet together).
Play: food = tame (1/3 chance). Right-click = sit/stand. Shift+right-click = GUI.
GUI slots: hand, boots, legs, chest, helmet, then storage. Spawn egg in creative.
